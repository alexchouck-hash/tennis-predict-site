Drop-in analysis script and edge evaluation module for [`Kalshi/kalshi-starter-code-python`](https://github.com/Kalshi/kalshi-starter-code-python) and [`Kalshi/tools-and-analysis`](https://github.com/Kalshi/tools-and-analysis).

## ⚡ Key Highlights

- **100% Free & Open**: Zero authentication required to consume live prediction data.
- **Audited Track Record**: Benchmark metrics, out-of-sample accuracy (57.2% across 1,500+ matches), and closing-line value (+0.99pp CLV) documented transparently at `https://ipredictsport.com/track_record.json`.
- **Zero Maker Fees**: Tailored for Kalshi limit orders where makers pay 0% in fees.
- **Quarter-Kelly Sizing**: Protects bankrolls from overbetting with mathematically rigorous position sizing.

## 🚀 Quickstart

1. Place `ipredict_starter_tool.py` in your Kalshi starter directory.
2. Run:
   ```bash
   python ipredict_starter_tool.py
   ```
3. Combine with `client.create_order()` from `kalshi-starter-code-python` to automate resting limit orders.
