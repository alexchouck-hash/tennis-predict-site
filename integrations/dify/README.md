# Dify Tool Integration: iPredictSport Tennis & Market Alpha

Connect your LLM apps and agents built on [Dify](https://github.com/langgenius/dify) to live ATP/WTA machine learning predictions from iPredictSport.

---

## ⚡ Features

- **100% Free**: Connects to `https://ipredictsport.com/predictions.json` with zero API keys required.
- **Audited Accuracy**: Live benchmark verification at `https://ipredictsport.com/track_record.json`.
- **Quarter-Kelly Sizing**: Built-in mathematically sound bankroll stakes.

---

## 🚀 How to Add to Dify

1. In your Dify Workspace, navigate to **Tools > Custom Tool**.
2. Upload or paste `ipredict_dify_tool.py`.
3. Select the tool in your Agent / Workflow node.
